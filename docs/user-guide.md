# User Guide

## Getting Started

To use this interactive gift application, you'll need:

1. A printed book containing:
   - A QR code that links to the application
   - A specific block of text for the OCR challenge
2. A modern web browser (Chrome, Firefox, Safari, or Edge)
3. A device with a camera (for the OCR challenge)

## Experience Flow

### 1. QR Code Scanning
- Locate the QR code inside the printed book
- Scan the QR code with your mobile device's camera or QR scanner app
- The application will open in your web browser

### 2. Welcome Screen
- You'll be greeted with a personalized welcome message
- Click the "Begin the Journey" button to start

### 3. Chess Puzzle Challenge
- You'll see a chessboard with a specific arrangement of pieces
- Your goal is to solve the chess puzzle by making the correct sequence of moves for White
- The application will automatically respond with Black's moves
- If you make an incorrect move, the piece will snap back to its original position
- Upon delivering checkmate, you'll see a success message

### 4. OCR Text Recognition
- You'll be prompted to use your device's camera
- Click "Start Camera" to activate the camera
- Point your camera at the specific block of text printed in the book
- Click "Capture" to take a photo of the text
- Click "Process Image" to perform OCR on the captured text
- If the text matches the expected content, you'll proceed to the next step

### 5. Secret Reveal
- You'll see the text from the book displayed in a grid
- Use the opacity slider to gradually reveal a hidden message
- The secret message "davidesthirty" will be revealed

### 6. Final Gift
- The secret message will appear as a clickable link
- Click the link to access your personalized gift

## Troubleshooting

### Camera Issues
- Ensure you've granted camera permissions to the browser
- Check that no other application is using the camera
- Try refreshing the page and retrying

### OCR Recognition Problems
- Ensure the text is well-lit and in focus
- Hold the camera steady when capturing the image
- Make sure the entire block of text is visible in the frame

### Chess Puzzle Help
- The puzzle has a specific solution sequence
- If you're stuck, try restarting the application
- Each incorrect move will be reverted automatically

## Technical Information

### Privacy
- All processing happens locally in your browser
- No data is sent to any server
- The camera image is processed locally and never uploaded

### Browser Support
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

### Offline Usage
- Once loaded, the application can work offline
- However, the initial load requires an internet connection
