# Interactive Gift Application

This is a standalone version of the Interactive Gift Application. You can run this application by simply opening the `index.html` file in your web browser.

## How to Use

1. Navigate to the folder containing this application
2. Double-click on `index.html` to open it in your default browser
3. The application will load and you can start using it

## Features

The application includes:
- Welcome screen
- Chess puzzle challenge
- Reveal module with OCR functionality
- Interactive elements and animations

## Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- Internet connection (for initial load, some features may require online access)

## Files

- `index.html` - Main HTML file
- `main.*.js` - Application JavaScript code
- `images/` - Image assets used in the application
